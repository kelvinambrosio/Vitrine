# Minha Vitrine

Marketplace brasileiro: qualquer pessoa abre sua loja grátis e vende para todo o Brasil. A plataforma cobra 5% sobre o valor dos produtos de cada venda concluída, sem mensalidade.

Stack: Next.js, Supabase (banco, login e fotos) e Mercado Pago (pagamentos com divisão automática).

Para colocar no ar, siga o passo a passo do arquivo [GUIA.md](GUIA.md). As chaves e senhas ficam em variáveis de ambiente (modelo em `.env.example`); nunca envie o arquivo `.env.local` para o GitHub.
